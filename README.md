# Quayside

Open-source desktop system for container shipping agencies: bills of lading, container
lifecycle (release-to-shipper, full return, empty return), demurrage/detention, invoicing
and Excel interchange. Windows (WPF), .NET 8, SQLite or PostgreSQL. MIT licensed.

> Work in progress — see `docs/SPEC.md` for the functional specification.

**Independent reimplementation.** Quayside is written from scratch from a functional
specification. It is not affiliated with, endorsed by, or derived from the source code of
the vendor of any legacy system whose workflows or file formats it supports.
